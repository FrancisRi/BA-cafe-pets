# 0.2.4 · 首次操作提示

- 首次启动在角色下方显示“右键打开菜单”，打开菜单后永久隐藏。
- 发行默认配置明确开启首次提示，升级保留用户的已读状态。

# 0.2.3 · 跟随距离与独立移动设置

- 在跟随区间内不启动移动，越界后移动到中点；最近距离可为 0，此时不主动远离鼠标。
- 全局“允许散步”和战斗“允许走动”分别控制无输入散步和持续输入短走，位置跟随独立。
- 菜单卡片、按钮、开关等统一方角风格；兼容旧版 Walking 设置。

# 0.2.2 · 收紧屏幕边界判定

- 按当前待机姿势各网格实际绘制的顶点缓存停靠范围，排除未引用的共享 accessor 顶点。
- 按角色实际朝向投影边界，移除大包围盒的重复旋转预留；额外留白保持 2 像素。
- 旋转后检查停靠位置，渲染范围、模型大小及动画保持不变。

# 0.2.1 · 多角色优化与默认参数

- 并行计算各角色动画和 CPU 蒙皮，仅处理三角形实际使用的顶点；OpenGL 和窗口提交保留在主线程。
- 角色屏幕边界额外留白减半，由 4 像素改为 2 像素。
- 发行默认参数采用当前用户设置；新用户设置和“恢复默认”使用同一份 defaults.ini。
- 菜单宽度缩小 7.5%，保留原字体大小和全部设置内容。

# 0.2.0 · 原生发行版

- raylib + 独立 cgltf 适配层直接读取原始 GLB，省去 Blender 转换和 WebView2。
- 保留多套蒙皮、完整节点层级、原生插值与 Morph 表情；使用透明 Win32 悬浮窗口。
- 咖啡厅／战斗行为、共享设置、最多 5 个角色与 15 条历史、鼠标跟随及避让。
- 右键点击打开菜单，右键拖动旋转；咖啡厅待机以 75% 速度播放。
- Retreat 位移先慢后快；Ibuki 拖动时对缺少替代面的收缩 Morph 加入保底。
- 缓存骨架与蒙皮计算、显示范围和命中区域；实际帧率仍取决于模型和显示规模。
- 提供包含默认 Shiroko、参数和第三方许可的单 EXE，以及便携 ZIP。

本次仅构建与核对发行包完整性，没有运行自动视觉测试。
